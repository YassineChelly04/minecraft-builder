Step-by-step Data Flow

# From → To What travels File Type
1 User → Web UI Text prompt + X/Y/Z origin coordinates index.html UI
2 Web UI → Flask POST /generate { prompt, origin: {x,y,z} } app.py Python
3 Flask → Orchestrator Raw user prompt string orchestrator.py LLM
4 Orchestrator ↔ Groq API LLM call #1 → returns intent JSON
{ structure_type, size, style, materials }		 orchestrator.py External
5 Orchestrator → Planner Intent JSON + origin coordinates planner.py LLM
6 Planner ↔ Groq API LLM call #2 → returns list of /fill and /setblock commands planner.py External
7 Planner → Validator Raw command strings to check validator.py Python
8 blocks.py → Validator Set of ~200 valid minecraft:block_name strings blocks.py Python
9 Validator → Flask { valid: bool, errors: list } — blocks execution if invalid validator.py Python
10 Flask → Web UI { commands[], valid, errors[], intent } — shown as preview app.py UI
11 Web UI → Flask POST /execute { commands[] } — triggered after 3-sec countdown app.py Python
12 Flask → Input Agent Ordered list of /fill and /setblock strings input_agent.py Auto
13 Input Agent → Minecraft Press T → paste via clipboard → Enter → wait 400ms → repeat input_agent.py Auto
